Wave Accounting books, 2025-01-01 to 2025-12-31, converted by Wave Exit 0.3.0 on 2026-01-20.

What this is

This folder holds everything Wave Exit read from Wave for this business, as plain CSV files any accounting program or spreadsheet can open, with the receipts and a tie-out report showing the books hold together. It is a complete archive: every other Wave Exit output can be rebuilt from it.

It was built from Wave's transactions export together with a Wave connection, so the chart of accounts is complete and balances were compared with Wave.

The ledger is always the full history. The cutover date (2025-12-31) and scope (full-history) recorded in manifest.json are used by outputs that load the books into another system.

Conventions

  • Text is UTF-8 with a byte-order mark, so Excel opens it with the right characters. Lines end with CRLF.
  • Dates are YYYY-MM-DD.
  • Amounts are in USD, written as plain decimals with 2 decimal places. Debits and credits are two columns of positive amounts.
  • IDs are stable: running Wave Exit again on a newer export gives the same IDs for the same records.
  • The CSV files are data, not formulas. If a text cell starts with =, a spreadsheet may treat it as a formula; open the files through the Wave Exit Excel workbook when that matters.
